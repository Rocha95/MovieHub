# 🎬 MovieHub

Sistema Full Stack desenvolvido para gerenciamento de filmes utilizando a API do TMDB.

## Objetivo

O projeto tem como objetivo permitir que usuários pesquisem filmes, organizem uma biblioteca pessoal, recebam recomendações e acompanhem informações sobre bilheterias.

## Tecnologias

- React
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- JWT
- Tailwind CSS
